# Business Sage reusable GitHub visual template

Edit `github_social_preview_EDITABLE.svg` in a vector editor or text editor. Replace the branded heading, tagline, descriptions and skill count as needed, then export as a JPG/PNG at 1280 × 640 px. The final image must be under 1 MB for GitHub social preview.

This is a **normal editable SVG**, not an installed ChatGPT personal template skill. The original GitHub-ready JPG lives at `../assets/github_social_preview_1280x640.jpg` and is already optimized. If your export uses the Inter font, install it independently from a licensed source or use a fallback. Font files are not included.
