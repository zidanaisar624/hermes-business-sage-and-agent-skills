# GitHub Publishing & Social Preview Guide — Business Sage

Recommended new repository URL:
`https://github.com/zidanaisar624/hermes-business-sage-and-agent-skills`

## 1. Create the Empty Repository on GitHub
1. Open https://github.com/new
2. Repository name: **`hermes-business-sage-and-agent-skills`** (leave *"Initialize this repository with a README"* **unchecked** so it starts empty).
3. Click **Create repository**.

## 2. Publish with 1 Command from PowerShell
From inside this folder (`hermes-business-sage-and-agent-skills`), run:

```powershell
.\push_to_github.ps1 -RepoUrl "https://github.com/zidanaisar624/hermes-business-sage-and-agent-skills.git"
```

*(Uses safe standard `git push -u origin main` — never `--force`.)*

## 3. Set GitHub "About" Description (`<= 350` chars, Respectful to Business Students)
Click the gear icon next to **About** on your GitHub repo page and paste:

```text
Business Sage + 49 Collaborative AI Skills: internet-researched S1–S2 (BBA/MBA) Strategy, Finance & Indonesian UMKM/Tax Advisor (Co-Pilot respecting business students & practitioners, NOT a replacement) + Eternal-Student Trend & Rp0-Bootstrap CLI (CLI-Anything ready for Hermes, OpenClaw, ChatGPT & Claude). Fun experiment by Gemini & 100% free.
```

**Suggested Topics:** `ai-agents`, `business-intelligence`, `financial-modeling`, `hermes-agent`, `cli-anything`, `indonesia`, `umkm`, `agent-skills`, `openclaw`

## 4. Upload GitHub Social Preview Image (Separate Step!)
1. On GitHub, go to **Settings → General → Social preview → Edit → Upload an image...**
2. Select `assets/github_social_preview_1280x640.jpg` (`1280 × 640 px`, `< 1 MB`).
